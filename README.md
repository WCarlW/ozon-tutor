# Ozon 导师 Agent

一个基于 TRAE 云端项目 + 飞书生态的 Ozon 跨境电商导师 Agent，帮助中国卖家从 0 开始在 Ozon 平台做跨境电商。

## 架构

```
交互层（TRAE PC/移动端）→ 智能层（TRAE 云端项目）→ 数据层（飞书 Wiki/Base）→ 外部接入（分阶段）
```

## 项目结构

```
ozon-tutor/
├── .trae/
│   ├── rules/
│   │   └── ozon-tutor.md          # Ozon 导师核心规则
│   ├── agents/
│   │   ├── ozon-analyst.md        # 数据分析子智能体
│   │   ├── product-scorer.md      # 选品打分子智能体
│   │   └── listing-optimizer.md   # Listing 优化子智能体
│   ├── mcp.json                   # MCP 配置（阶段 2 启用 Ozon API）
│   └── settings.json              # 项目设置
├── docs/
│   ├── knowledge-map.md           # 知识库分类索引
│   └── stage-checklist.md         # 各阶段检查清单
├── scripts/
│   ├── ozon_api_client.py         # Ozon API 客户端（阶段 2）
│   └── roi_calculator.py          # ROI 计算器（阶段 2）
└── README.md
```

## 快速开始

1. **在 TRAE 中打开项目**：从 GitHub 拉取本仓库作为云端项目
2. **配置飞书**：
   - 创建飞书 Wiki 知识库，按 `docs/knowledge-map.md` 的分类组织内容
   - 创建飞书 Base 多维表格，包含：商品表、任务表、决策日志表、状态快照表、ROI 表
3. **开始对话**：在 TRAE 中打开本项目，直接与 Ozon 导师对话

## 阶段路线图

- **阶段 1（现在～出第一单）**：政策问答、选品打分、Listing 优化、任务管理（零成本）
- **阶段 2（出单后）**：Ozon API 自动同步数据、ROI 计算、库存预警
- **阶段 3（稳定盈利后）**：接入付费选品工具、竞品监控、关键词分析
